## Modifying verification software and libraries

The integrity manifests identify the original released files. They are not
an access control or a prohibition on permitted modifications. Recipients may
modify the software within the applicable licenses, including replacing
compatible library components. A modified tree is no longer byte-identical
to the original release; its mathematical results must be checked using its
own inputs and programs. See third_party/runtime/REPLACEMENT.md for the
library replacement procedure and its supported scope.

## Attribution when reusing this collection

Preserve the copyright and permission notices required by the licenses of
the files you copy. Credit mathematical sources when using their results,
methods or constructions. Identify modifications accurately and avoid
implying endorsement by the original authors. Cite the precise repository
version when relying on its programs or certificate data, alongside the
relevant original mathematical references.

The scholarly citation guidance is separate from the binding license terms.
It does not add a permission condition or restriction to any bundled license.

A license inventory records the materials and license terms identified for
this release. It is not a judicial determination of rights in every
jurisdiction. If a specific provenance or permission issue is identified,
please contact the maintainer with the affected file and source so that it
can be investigated and corrected.
